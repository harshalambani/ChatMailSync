WA Mail Sync Portable

Archive WhatsApp chat exports to your own mailbox over IMAP, as threaded emails.

What it does

You export a chat from WhatsApp; WA Mail Sync turns it into email and files it in your mailbox, one thread per chat, so the conversation is searchable and backed up wherever your mail already lives.

It is one-way and write-only. It appends messages to your mailbox and does nothing else — it never reads your existing mail, never deletes anything, and never sends mail to anyone. Nothing is uploaded anywhere except the mail server you configure yourself.

First run

  1. Launch WAMailSyncPortable.exe.
  2. Open Settings and enter your mail server, port, email address and app password. Use an app password issued by your provider — not your main account password. The app will offer instructions for common providers.
  3. Export a chat from WhatsApp (Chat → More → Export chat) and drop the .txt or .zip into the app window, or into Data\data\inbox\.
  4. Run the sync. Processed exports are moved to Data\data\processed\, and a local record of what has already been sent keeps repeat runs from duplicating messages.

Where your data is kept

Everything stays inside this package's Data\ folder. Nothing is written to the host machine's registry, user profile, or Program Files.

PathContents
Data\auth\Your saved mail credentials.
Data\data\inbox\Exports waiting to be synced.
Data\data\processed\Exports already synced.

Copy or move the whole folder and it keeps working — nothing is tied to an absolute path. The launcher sets WAMAILSYNC_ROOT to this Data\ folder for you.

How your app password is protected

The app password is the only secret this program stores. On Windows it is encrypted with the Data Protection API before it is written to disk, and the file it lives in has its inherited permissions stripped so that only your Windows account can open it. It is never written to a log, never shown back to you after saving, and never included in an error message.

Portability caveat, worth knowing before you move this to another machine. That encryption is deliberately tied to your Windows user account on this computer. If you carry the package to a different PC, or use it under a different Windows account, the saved password cannot be decrypted there and the app will ask you to enter it again. That is the protection working as intended, not a fault — nothing has been lost, and the app password is still valid at your provider.

If you would rather the drive not carry the credential at all, use Forget saved password in Settings before unplugging it.

Known limits

  • Network and UNC paths are untested. Running the package from a mapped network drive or a \\server\share path may work, but the local database it keeps does not behave reliably over SMB, and it can fail quietly rather than loudly. Run it from a local disk or a USB drive.
  • This is a beta. Treat your mailbox as the copy that matters and keep the original exports until you have confirmed the results look right.
  • Media files referenced by an export are handled as attachments where the export includes them; a text-only export has no media to attach.

Uninstalling

Delete the package folder. There is nothing else to remove — no registry keys, no files outside it. Anything already archived stays in your mailbox, since that copy belongs to your mail account rather than to this program.
